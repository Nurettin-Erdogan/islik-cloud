# İşlik Cloud

Küçük servis işletmeleri için müşteri, iş, ödeme ve takvim yönetim sistemi.

Bu proje, mevcut local-first İşlik uygulamasının full-stack cloud sürümüdür.

## Amaç

İşlik Cloud; teknik servis, tamirci, küçük işletme ve saha hizmeti veren ekiplerin müşteri kayıtlarını, iş süreçlerini, ödeme durumlarını ve günlük operasyonlarını tek panelden yönetmesini hedefler.

## Planlanan Özellikler

- Kullanıcı hesabı
- Giriş / kayıt sistemi
- Müşteri yönetimi
- İş takibi
- Ödeme durumu takibi
- Dashboard
- Raporlar
- Takvim görünümü
- PostgreSQL veritabanı
- REST API
- React frontend
- GitHub Actions CI
- Docker desteği

## Planlanan Teknolojiler

### Frontend

### Backend
